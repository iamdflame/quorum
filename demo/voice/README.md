Put your ElevenLabs audio here, named `01.mp3` through `11.mp3` — one file per
block in [SCRIPT.md](../SCRIPT.md) — then run `./demo/assemble.sh`.

`.mp3`, `.wav`, `.m4a`, `.aac` and `.ogg` all work. Eleven separate files, not
one long one: separate files are what let the assembler time each shot to the
line spoken over it.
